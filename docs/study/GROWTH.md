# 📈 성장 지표 추적 (Growth Tracker)

> 목적: 내 실력이 **실제로 성장하는지** 객관적으로 추적. 매주 화요일 체크 → 방향 조정.
> 측정 방식: 세션에서 보인 **증거 기반**(냉정하게). 막연한 느낌 X.
> 최종 목표: 깊이 있는 개발자 → 아키텍트 + 솔로빌더 ([[project_study_roadmap]])

---

## 📏 측정 축 (5개)

| 축 | 뭘 보나 |
| --- | --- |
| **① 개념·데이터흐름 이해** | 전체 흐름 추적, "왜?" 설계 사고, 밑바닥 이해 |
| **② 타이핑(백지 생산)** | 힌트 없이 코드 생산, 문법 함정 빈도 |
| **③ 넓이(패턴 다양성)** | 경험한 기능 종류 수 (폼·auth·결제·테스트…) |
| **④ 디버깅·문제해결** | DevTools·Network·이분탐색, 독립 디버깅 |
| **⑤ 메타인지·학습력** | 자가점검, 막혔을 때 회복, "왜?" 지속력 |

## 🏁 기준선 — 2026-10-27 (baseline)

| 축 | 수준 | 증거 |
| --- | --- | --- |
| ① 개념·흐름 | **2년차+** (이해 깊이는 그 이상) | 생성흐름(DB→타입→훅→route→service) 스스로 다이어그램화·검증. "왜 Request 타입/export/Promise 누가 await" 밑바닥 질문 |
| ② 타이핑 | **1년차 초반** | 설계도 주면 전체 침. 근데 고정 함정 반복: `!res.ok`·`()=>`·`Omit<Purchase>` 감싸기·`??`↔`?`·단복수·오타. 힌트 필요 |
| ③ 넓이 | **신입~1년차** | 깊게 판 건 cart·상품조회·주문생성 3개뿐. 폼·auth·무한스크롤·낙관적업데이트·테스트·성능 안 해봄 |
| ④ 디버깅 | **1년차** | git·husky·"상품 안 불러옴" 추적. DevTools/Profiler 독립 디버깅은 아직 |
| ⑤ 메타인지 | **최상** (실력보다 위) | "내 방식 효율적?/수준?" 자가점검, "전혀 모르겠다"→포기 안 하고 다이어그램 완성 |

**종합:** 주니어 초반, **"이해 >> 생산·넓이" 불균형**(이해형 학습자). 강점=이해·메타인지(희소). 격차=타이핑 속도·넓이(둘 다 방법 명확: 반복·다양화).

**비율 목표:** (지금) 이해70/타이핑25/넓이5 → (바꿀) **이해40/타이핑35/넓이25**

## 🧭 스터디 방향 (기준선 기반)

- **유지:** 데이터 흐름 "왜?" 깊게 (최대 무기)
- **추가:** ① 세션 시작 함정 드릴(손 속도) ② 한 기능 깊게 후 **새 패턴 얕게**(넓이) ③ **토대 깊게 / 디테일 룩업**(토끼굴 자제)
- **줄이기:** 문법 미세사항(괄호·fetch옵션) 오래 머물기

## 🐛 디버깅 일일 커리큘럼 (하루 1개, 공부하면서 제안)

> 매 학습 세션에 **디버깅 미니 주제 1개**를 섞는다 (아래 로테이션). 개념만 말고 **실제로 한 번 해보기**.

1. **Console** — 에러 메시지 끝까지 읽기 (대충 넘기지 말기)
2. **Network 탭** — 요청/응답·상태코드·payload 확인 (fetch가 뭘 보냈나)
3. **React DevTools (Components)** — props·state 들여다보기
4. **React DevTools (Profiler)** — 리렌더 측정 (왜 다시 그려지나)
5. **React Query DevTools** — 캐시·쿼리·mutation 상태
6. **이분 탐색** — 범위 반씩 좁히기 (어디서 터지나)
7. **console.log / breakpoint 전략** — 어디에 찍나
8. **"최근 바뀐 것부터 의심"** — git diff로 범위 좁히기
9. **에러 메시지 역추적** — "A인데 B 왔다" 읽는 법
10. **타입 에러 디버깅** — hover로 추론 확인

→ 돌면서 반복. 실제 코드에서 한 번씩 써보면 손에 붙음.
