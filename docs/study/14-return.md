# 14. 리턴 — 함수를 부른 "자리"가 결과값으로 바뀐다

> 한 줄: **리턴 = 함수가 결과를 밖으로 내놓는 것. 핵심은 "함수를 부른 그 자리가 리턴값으로 바뀐다(치환)".** `add(2,3)` 자리가 `5`가 되고, `persist(...)` 자리가 "감싼스토어"가 된다 — 똑같은 원리.
> 함수 문법 밑바닥 [[11-function-syntax]] ① · 커링 [[07-currying-create]] · persist 실행타이밍 [[11-function-syntax]] ⑬.

---

## 🎯 리턴 = "결과를 밖으로 내놓는 것"

```js
const add = (a, b) => {
  return a + b     // ← "계산 결과를 밖으로 내놔라"
}
```

함수는 안에서 일하고, 그 결과를 밖으로 **뱉는다.** 그게 리턴.

---

## ⭐ 진짜 핵심 — 부른 "자리"가 리턴값으로 바뀐다 (치환)

이게 리턴의 열쇠. `add(3, 4)` 라고 쓰면, 실행 후 **그 자리에 `7`이 남는다.**

```js
add(3, 4)
   ↓ 실행되면
   7          ← "add(3,4)" 글자가 통째로 "7"로 바뀜
```

**치환** = 함수 호출을 지우고 그 자리에 리턴값을 끼워넣는 것:

```js
const x = add(3, 4)          →  const x = 7          // x = 7
const y = add(3, 4) + 10     →  const y = 7 + 10     // = 17
```

> 🥤 자판기: `add(3,4)` = 돈 넣고 버튼 누름 / `7` = 나온 음료. **나온 음료가 리턴.**

---

## 🪜 한 걸음씩 풀기 (double 예제)

```js
const double = (n) => { return n * 2 }
const result = double(5) + 1
```

```
1걸음: double(5)  → n=5 → return 5*2 → 10       (double(5)는 10을 리턴)
2걸음: double(5) 자리를 10으로 바꿈 → 10 + 1
3걸음: 10 + 1 = 11
```

→ **`result = 11`**

---

## 🔁 함수가 여러 개면 → 각각 바꾼 뒤 계산

```js
const x = add(2, 3) + add(1, 1)
```

```
add(2,3) → 5      add(1,1) → 2
        ↓ 각각 치환
   5     +    2
        ↓
        7
```

→ **`x = 7`**. 여러 개 있어도 **각각** 리턴값으로 바꾼 다음 계산.

---

## 📥 리턴값을 "받는" 3가지 방법

```js
const x = add(3, 4)          // ① 변수에 담기          → x = 7
console.log(add(3, 4))       // ② 다른 함수 인자로 넣기  → console.log(7)
const total = add(3, 4) * 2  // ③ 계산에 바로 쓰기       → 7 * 2 = 14
```

셋 다 공통: **`add(3,4)` 자리가 `7`로 바뀐 다음** 그걸 쓴다.

---

## ⚠️ 리턴이 없으면 → `undefined`

```js
const shout = (msg) => {
  console.log(msg)     // 일은 하는데 return 없음
}
const x = shout('안녕')  // '안녕' 출력은 되지만 x = undefined
```

→ 리턴 = "밖으로 내놓는 것". 안 내놓으면 받을 게 없다(undefined).

---

## 🛒 우리 프로젝트 — persist / create (치환이 두 번)

`add(2,3)`이 `5`로 바뀌던 그대로, 라이브러리 함수도 똑같이 치환된다.

```
create<CartStore>()( persist(콜백, {name}) )
                     └────────┬─────────┘
              persist(...) 실행 → "감싼스토어" 리턴 → 그 자리에 앉음
                     ↓ 치환
create<CartStore>()( 감싼스토어 )
                     ↓ 이것도 실행 → "완성된 스토어" 리턴
완성된 스토어  →  useCartStore 에 담김
```

- **1차 치환:** `persist(...)` → 감싼스토어 (persist의 리턴값)
- **2차 치환:** `create()(감싼스토어)` → 완성 스토어
- 지금은 **1차(persist→감싼스토어)만** 확실히 잡으면 충분.

> ⚠️ persist는 라이브러리(zustand) 함수라 **`return` 글자는 우리 코드에 안 보인다** (zustand 소스 안에 있음). 우리 코드엔 "부른 자리에 리턴값이 앉는 것"만 보인다.
> → 규칙(리턴 포함)은 **정의**에 적혀있다: 내 함수면 내 파일, 라이브러리면 그쪽. [[11-function-syntax]] ⑨

---

## ✅ 한 눈 요약

```
리턴 = 함수가 결과를 밖으로 내놓는 것

⭐ 핵심: 함수 부른 "자리"가 리턴값으로 바뀐다 (치환)
   add(3,4)     → 7          (그 자리에 7이 앉음)
   double(5)    → 10
   persist(...) → 감싼스토어   (그 자리에 앉아 create 괄호로)

여러 개: 각각 바꾼 뒤 계산   add(2,3)+add(1,1) → 5+2 → 7
받는 법: ① 변수  ② 다른 함수 인자  ③ 계산에 바로
리턴 없으면: undefined (내놓은 게 없음)
라이브러리 함수: return 글자는 그쪽 소스에 있음 (우리 코드엔 리턴값만 보임)

🥤 자판기: 돈 넣고 버튼 → 음료(리턴) 나옴 → 그 음료를 씀
```

> 🔑 리턴 = **부른 자리에 결과가 앉는 것.** 이거 하나면 add도 persist도 다 똑같이 읽힌다.
